# Resume and CV for Personal use

I use the [modern-cv](https://github.com/schochastics/modern-cv) template that was inspired by the [LaTex CV and Resume Collection](https://github.com/jankapunkt/latexcv) to create my resume. Currently I have a one page CV resume created with the adjustments made to look exactly as you need. This can be done by making changes in the template.tex file within the _extension folder. In my experience some changes was needed to make it work exactly as I needed it to be for my use case. Check out the original sources for making your own or use the copy the folder Resume/1-page and edit the .qmd for a quick resume of your own.

I also wanted to be able to share my resume with an online line so that any changes I make is always avaialbel to anyone using that link. For this I created a Quarto website and linked the resume on the website. So every time I made modifications to my Resume, I do the following:

1. Render the resume.qmd to pdf.  
2. Render the index.qmd of my resume website.  
3. Push the changes to GitHub.

This makes sure that my resume is always upto date and ready to be shared. 

The Resume [website](https://anoobvinu07.github.io/Resume_CV/) is barebones and is used to just host the online version of my [resume](https://anoobvinu07.github.io/Resume_CV/Resume/1-page/prakash_resume_1page.pdf).
